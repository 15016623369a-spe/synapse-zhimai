# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

Be respectful, constructive, and patient. Harassment, discrimination, and
personal attacks are not tolerated. Maintainers may remove comments, close
issues, or ban contributors who violate these expectations.

Report concerns privately to the maintainers via GitHub's report/contact
mechanism for this repository. Enforcement decisions will be made in good faith.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
